JKS

List all entries:

keytool -list -v -keystore {{ result.serialNumber }}.jks -storepass {{ result.keystorePassword }}

Export certificate (alias is always cert-{serial}):

keytool -exportcert -alias "cert-{{ result.serialNumber }}" -keystore {{ result.serialNumber }}.jks -storepass {{ result.keystorePassword }} -rfc -file {{ result.serialNumber }}.pem

PKCS12 (.p12)

List all entries:

keytool -list -v -keystore {{ result.serialNumber }}.p12 -storetype PKCS12 -storepass {{ result.keystorePassword }}

Export certificate:

keytool -exportcert -alias "cert-{{ result.serialNumber }}" -keystore {{ result.serialNumber }}.p12 -storetype PKCS12 -storepass {{ result.keystorePassword }} -rfc -file {{ result.serialNumber }}.pem

OpenSSL — see everything (cert + private key):

openssl pkcs12 -info -in {{ result.serialNumber }}.p12 -passin pass:{{ result.keystorePassword }} -nodes

OpenSSL — cert info only:

openssl pkcs12 -in {{ result.serialNumber }}.p12 -nokeys -passin pass:{{ result.keystorePassword }} | openssl x509 -text -noout

OpenSSL — verify private key is present:

openssl pkcs12 -in {{ result.serialNumber }}.p12 -nocerts -nodes -passin pass:{{ result.keystorePassword }}
